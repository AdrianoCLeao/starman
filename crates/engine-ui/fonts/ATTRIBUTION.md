# Bundled fonts

`Inter-Regular.ttf` and `Inter-Bold.ttf` are from **Inter 4.0** by Rasmus
Andersson and the Inter project authors
(<https://github.com/rsms/inter>, release `v4.0`, files
`extras/ttf/Inter-Regular.ttf` and `extras/ttf/Inter-Bold.ttf`), unmodified.

They are licensed under the **SIL Open Font License 1.1**; the full license
text is in `LICENSE.txt` next to this file. The fonts are embedded in
`engine-ui` as the default UI typeface so text renders identically on every
machine (no dependency on system fonts), and are also copied into the
reference project as a project font asset.
